# Evaluation Guide & Criteria

## Evaluation Guide

There can be multiple approaches to solving this problem, but the best possible approach we recommend is:

1. Start with a **base SQL query** that selects all the data from the table.  
2. Based on user interactions with the buttons, dynamically update the filtering conditions in the query.  
3. On submission, execute the dynamically generated query and display the filtered results in the dashboard.

---

## Evaluation Criteria

**Total: 10 Points**

- **Import movie data into SQL and display it in the dashboard** – **3 Marks**  
- **Dynamically update the dashboard using button interactions** – **4 Marks**  
- **Export selected/custom data to CSV** – **3 Marks**
